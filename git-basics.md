\# Git Fundamentals



\## What Is Git?



Git is a distributed version control system that tracks

changes made to files during software development.



\## What Is GitHub?



GitHub is an online platform for hosting Git repositories

and collaborating with other developers.



\## What Is a Repository?



A repository is a project whose files and history are

tracked by Git.



\## What Is a Commit?



A commit records a snapshot of staged changes.



\## What Is a Branch?



A branch is an independent line of development within

a Git repository.



\## What Is the Staging Area?



The staging area contains changes selected for the next

commit.



\## Basic Git Workflow



1\. Create or modify project files.

2\. Check changes using git status.

3\. Review tracked changes using git diff.

4\. Stage changes using git add.

5\. Save changes using git commit.

6\. Upload commits using git push.
