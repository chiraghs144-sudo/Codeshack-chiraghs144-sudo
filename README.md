\# Developer Handbook



\## About This Project



The Developer Handbook is a learning project created for

the CodeShack Week 1 Git and GitHub assignment.



It documents essential Git commands, version control,

branching, and collaboration workflows.



\## Objectives



\- Understand Git and GitHub.

\- Learn essential Git commands.

\- Practise version control using Git CLI.

\- Understand commits and branches.

\- Learn how developers collaborate on projects.



\## Tools Used



\- Git

\- GitHub

\- Git Bash

\- Markdown



\## Learning Outcomes



This project demonstrates how Git tracks file changes,

maintains project history, manages branches, and helps

developers collaborate efficiently.
